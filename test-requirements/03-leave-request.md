# Test requirement 3: Leave request flow

**Paste this into DesignPilot:**

Employees find it confusing to apply for leave in our HR app. They don't know how many days they have left, and managers miss approval requests. Design a simpler leave request and approval flow for employees and managers.

**What a good result looks like**
- Two user types (employee and manager) appear in every phase.
- Edge cases include no days left, overlapping dates, and a manager on leave.
- The prototype has both the employee and manager flows.
